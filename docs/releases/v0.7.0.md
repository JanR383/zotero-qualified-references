## Highlights

- **Reference list: search, stance filter, expand/collapse all.** The list window has a search field (author, year, title; all terms must match), one checkbox per stance, and "Expand all" / "Collapse all". Arrow Right and Arrow Left open and close the focused row.
- **Graph: highlight tags.** "Highlight tags" lists every tag in the current scope. Nodes with a selected tag get a ring in the tag's colour: Zotero's colour for coloured tags, otherwise one from a palette without the stance colours. "Only highlighted items and their neighbours" hides the rest, which shows which literature points to, for example, your primary sources. The selection is remembered.
- **Views update right away.** When item A gains or loses a reference to B, B's "Referenced by" list and its Ref. (+)/(−) cells update without selecting B again.
- **Leaner plugin.** It no longer bundles zotero-plugin-toolkit, which wrapped some of Zotero's own item functions at startup. The XPI shrinks from 140 KB to 117 KB.

## Fixes

- Items in the trash no longer appear as targets in the graph and the list. They come back when restored.
- Picking a note or attachment as a target now adds a reference to its parent item. Standalone notes and attachments, trashed items and the item itself are skipped.
- If the highlight behind a PDF anchor has been deleted, the item pane shows "(highlight deleted)" instead of a link that does nothing.
- The graph's edge-length slider is now saved between sessions.
- At startup, only items that carry references are loaded to build the index (previously every regular item).

## Notes

- Popups after creating a reference or stripping references from a group copy use Zotero's standard look and no longer show a tick icon.
- The item-list columns Ref. (+)/(−) now use Zotero 10's `registerColumn`, with a fallback for Zotero 9.

## Compatibility

- Requires **Zotero 9 or 10**. The stored data format is unchanged from 0.6.0.

## For developers

- Node **22.18 or newer** is required (`engines`); `.nvmrc` and CI use Node 24.
- Debug-log entries now include error messages and stack traces.
- Item-pane styles live in `addon/content/qref.css`; stance names come from one table (`STANCE_LABEL_KEY`).

## Reference list redesigned

- **Incoming and outgoing references shown separately.** Each row shows how often the item is cited and how many references it makes, each with a count and a diverging stance bar (supporting to one side, contradicting to the other, colours from the chosen palette). The previous per-stance pill counts are gone.
- **Compact rows.** Collapsed rows take one line. Expanded entries use a grid, so the stance pill stays next to a long title instead of wrapping below it.
- **Show menu.** Filters the list to all items, items with own references, only cited items, contested items, only highlighted items, or items that are often cited but have no own references yet.
- **Search covers comments.** The search field matches title, author and comment; entries whose comment matches are expanded.
- **New sort orders.** "Most cited" and "Most references made" replace the former sort by number of references.
- **One toolbar row** with the stance toggles and a single expand/collapse button.
- **Tag highlighting in the list.** The list toolbar has the same tag picker as the graph. Selection and colours are shared between both windows; highlighted tags appear as coloured dots after the title (colour-blind palette included).
- Items without a creator are labelled with their publication or website title.

## Contested items

- An item is **contested** when one work cites it as supporting and another as contradicting. The list marks such items with a ± marker and can show only them.
- The graph has a matching filter, **Only contested items and their neighbours**. Combined with the tag focus, only items matching both are shown. When a filter leaves nothing to show, the graph now says that nothing matches instead of "no references yet".

## Graph window

- **Timeline and layers layouts removed.** The timeline crowded recent literature into a narrow band on its linear year scale, and the layer depth depended on how many references below an item had been entered rather than on the item itself. The settings `graphShowTimeline` and `graphShowLayers` are gone; the network and ego layouts remain.
- **Ego network improved.** The centre and all direct neighbours are labelled; the outer ring is labelled on hover, search or zoom. Items on each side are spaced evenly in height so side labels no longer overlap. The outer ring only keeps items linked to at least two direct neighbours. When all neighbours point in one direction, they use the whole circle.
- **Arrowheads scale with zoom.** Their length follows the zoom within 6 to 16 screen pixels and never exceeds 40 % of the visible part of an edge, so short edges still show their direction.
- The stance filter uses the same toggles as the list. Both windows use the system font, scaled by Zotero's font size setting.

## Fixes

- Editing a stance or comment in the item pane no longer makes the pane jump back to the top of its section. Item rows are now refreshed directly instead of through a Zotero notification that re-rendered the whole pane.

## Maintenance

- Updated development dependencies (eslint, @types/node, chai, mocha) and the pinned GitHub Actions `actions/setup-node` and `actions/upload-artifact`.

## Compatibility

- Requires **Zotero 9 or 10**. The stored data format is unchanged.

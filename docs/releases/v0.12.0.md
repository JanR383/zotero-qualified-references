## Incoming references in the item pane

- The **Referenced by** list has an **Add incoming reference** button. Each item picked in Zotero's item dialog gets a reference to the current item. As before, the reference is stored on the picked item, so each one is saved separately (one undo step per item on Zotero 10). Items in read-only libraries are skipped, and an item whose Extra field would exceed the sync size limit is left unchanged; both cases are reported in a notice.
- Incoming references can now be edited in place with the same editor as outgoing ones (stance, pages, comment, delete). Changes are written to the item that stores the reference. References from read-only libraries keep the compact read-only view.
- New setting **Add and edit incoming references under "Referenced by"** (item pane section of the settings, on by default). When off, the list is read-only and the add button is hidden, as in earlier versions.

## Graph window

- **Clusters kept apart.** In the network layout, groups of items that share no reference no longer mix into one tangle: each connected group is kept as its own area, and nodes inside a dense group keep a minimum distance. Repulsion now follows the edge-length slider. The layout is re-run when filters split or join groups. The timeline layout is unchanged.
- **Ego network layout.** One item sits in the centre. Items citing it are placed on a half circle to the left, items it cites on the right, mutual references above and below, and the next ring further out, faded. The centre starts at the item selected in Zotero (otherwise the first search hit or the most connected item); clicking an item or pressing Enter in the search makes it the new centre.
- **Layers layout.** Items are stacked by citation flow. Level 0 holds items that cite none of the items shown; each level above refers to items below it. Reference cycles are broken at one point so every item gets a level.
- **Layouts switched on individually.** Timeline, ego network and layers are each enabled separately in the settings (all off by default). With none enabled, the window shows no layout switch. Each layout button explains its layout in a tooltip; the same explanation appears in the settings.
- **Collapsible panels.** The legend and the controls panel can each be collapsed to a single line so the graph can use the whole window. The state is remembered.
- **Tag highlight colours.** Each highlighted tag gets a colour swatch in the tag picker with six colours plus "automatic" (the tag's Zotero colour, otherwise the first colour no other selected tag uses). With the colour-blind palette enabled, the six colours switch to a colour-blind-safe set based on Paul Tol's muted scheme.

## Fixes

- The graph tag picker lists selected tags first, in selection order. A highlighted tag that was renamed or deleted could not be deselected and kept counting in the button label; it is now shown dimmed and can be unchecked.
- The change journal no longer logs a deprecation warning on every Zotero start.

## Compatibility

- Requires **Zotero 9 or 10**. The stored data format is unchanged.

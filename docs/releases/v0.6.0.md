## Highlights

- **Zotero 10 support.** The plugin now runs on Zotero 9 and 10. Zotero 8 is no longer supported.
- **References into group libraries work on every device.** Previously a reference to an item in a group could show "(item not found)" on another computer or for another group member.
- **New icon.**

## Fixes

- **Group references across devices.** Zotero numbers libraries per device, so the stored target library could point to the wrong library elsewhere. References now also store a device-independent library reference. Existing references are found by their item key and upgraded automatically the next time the item's references are saved.
- **No lost edits in the item pane.** Changing a stance, page or comment no longer overwrites changes that arrived in the meantime (for example through sync or the PDF reader).
- **No stray highlights.** Cancelling the item picker after "Add qualified reference from here…" on a text selection no longer leaves a highlight behind in the PDF.
- **Fewer needless sync uploads.** Saving unchanged references no longer rewrites the Extra field.
- Items deleted while the reference index is being built at startup are no longer indexed.

## Compatibility

- Requires **Zotero 9 or 10**.
- The stored data stays readable by 0.5.x. If you use an older plugin version on another device, it still shows the references; the new library reference is re-added when this version saves the item again.

## For developers

- CI runs the test suite against both the released and the beta Zotero and reports the Zotero version.
- Build target raised to Firefox 140 (the platform of Zotero 9 and 10).

## Backup and restore

- **Settings → Qualified References → Backup** saves every reference of every library to one JSON file, with all fields (stance, pages, comment, PDF anchor, timestamps). Items are identified by library and key.
- **Restore…** merges such a file back. References an item no longer has are added again, and a reference edited later than in the backup is kept. Nothing is deleted. Items that are missing, in read-only group libraries or would exceed the sync size limit are skipped and counted.

## Change journal

- Before each change to an item's references, the previous state is kept in `qualified-references-journal.json` in the Zotero profile. The journal holds the last 10 states per item, stays on this device and is not synced.
- The item pane lists them under **Earlier states**, each with a **Restore** button. On Zotero 10, a restore can be undone with Edit → Undo.

## References removed by other tools

- When an item's `Reference-Graph:` line disappears or becomes unreadable without the plugin, a notice says so. The item pane then offers to restore the last state.
- To tell such removals apart, deleting an item's last reference now leaves an empty `Reference-Graph: []` line in Extra.
- Devices still running an older version remove the line instead, and other devices report that as a removal. Update all devices.

## Compatibility

- Requires **Zotero 9 or 10**.
- The stored format is unchanged apart from the empty line described above, and older versions read it without problems.
